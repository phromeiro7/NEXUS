## Refino de conforto visual (painel)

O relato foi de olhos doloridos. Causas e ajustes (antes para depois):

| Token | Antes | Depois | Motivo |
|---|---|---|---|
| Claro: fundo | `#edf0eb` | `#e7eae4` | menos brilho em área grande |
| Claro: superfície | `#f7f9f5` | `#f0f2ec` | cartões e listas quase brancos davam clarão |
| Claro: campo | `#fbfcf9` | `#f6f7f2` | campo ainda é a área mais clara, sem branco puro |
| Claro: texto | `#142d3a` (13,5:1) | `#1b333f` (10,9:1) | alvo 7 a 12:1, menos vibração |
| Escuro: fundo | `#11212a` | `#0f1b22` | mais fundo, sem preto puro |
| Escuro: superfície | `#182c37` | `#16262f` | camadas suaves |
| Escuro: texto | `#d5dfdd` (12,1:1) | `#c9d4d2` (11,5:1) | menos halation |
| Escuro: botão primário | `#8db2c1` | `#7ba0b0` | área grande clara cansava |
| Escuro: atraso / ok | `#eba791` / `#7cc4a0` | `#e6a58f` / `#78b898` | menos saturação, ainda 7:1 |
| Linha (divisória) | `#d5dcd6` / `#243e4b` | `#d0d7d0` / `#223943` | divisória discreta |
| Entrelinha base | 1,45 | 1,5 | |

Tipografia do painel: título de linha 17px, apoio 15px (antes 14px), tabela 16px (antes 15px), cabeçalho de tabela 15px, campo de captura 18px. `prefers-contrast: more` troca linhas por `--contorno` e aproxima o texto de apoio do principal; `prefers-reduced-motion` já zera transições.
